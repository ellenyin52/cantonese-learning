# 日日粤 · 90 天个人粤语学习计划

响应式粤语学习网页，支持 Mac 和 iPhone 浏览器。原生 HTML/CSS/JavaScript，无第三方运行时依赖。

## 最简单的打开方式

保存 `downloads/daily-cantonese.html` 到 Mac，用 Safari 打开，无需安装或启动服务。iPhone 推荐通过 HTTPS 托管网址访问；从文件 App 打开的预览可能不执行 JavaScript 或无法持久保存记录。当前没有自动部署的公网网址。

更新前：在旧版「我的足迹」中导出进度（旧版没有此功能时保留旧文件）。更新时尽量替换同一位置、同一名称的文件并使用同一浏览器，但本地文件的存储策略因浏览器而异，不能保证自动迁移；已有 JSON 备份可导入恢复。

## 90 天怎样安排

每天约 20 分钟：6 分钟词块、8 分钟生活表达、6 分钟自主练习。

共 15 个主题，每个主题 6 天，按以下节奏循环：

1. 新课：10 个基础词块、5 句场景表达，联系生活改写。
2. 新课：10 个扩展词块、5 句自然表达，练习较长句子。
3. 主动回想：混合前两天内容，看普通话尝试用粤语表达。
4. 听辨跟读：混合复习，隐藏文字听辨、揭晓跟读；没有可用粤语语音时改为读后复述。
5. 情景对话：根据主题任务扮演双方，更换条件重练。
6. 模块小测：不看笔记完成任务，自查说明需求、追问、回应变化的能力。

因此是 **30 天新课 + 60 天明确任务的复习、应用与自测**，不是 90 天都增加新词。每天均提供 10 个词条及 5 句表达（复习日有意重现学过的词句），配粤拼和普通话释义。开口练习是自主评估，不录音、不自动评分，完成 90 天不代表已获得某个语言等级。

| --- | --- |
| 1–6 | 日常问候与近况 |
| 7–12 | 餐厅点餐与口味 |
| 13–18 | 购物选择与比较 |

## 学习与打卡

- 新版首次打开默认「90 天计划」，以后记住选择；原有「零基础」「进阶入门」各 7 天课程保留，记录独立。
- 每个词句练习后，点击右上角 +。90 天计划和进阶模式还需完成并勾选当天开口练习，才可打卡。
- 每个学习日重新记录掌握情况，复习日不会继承另一课的完成勾选。
- 一天一课、一天一次打卡。日期按设备本地日期；当天打卡后保持该课，下一天继续下一课，中断不会跳课。连续天数在断档后重新计算。
- 课程目录可查看全部 90 天：未来课程只能预览，不能提前打卡；完成课程可随时复习。
- 完成第 90 天后停止增加课程打卡，可继续复习。
- 可暂停或继续计时；计时只在页面打开并启动后累计，不强制等满 20 分钟才可打卡。

## 粤语发音

词汇和对话支持普通速度、慢速与停止，使用浏览器 Web Speech API。仅使用 `yue` / `yue-*` / `zh-HK` 语音，绝不回退为普通话；无粤语声音时隐藏播放按钮，并显示配置说明。

推荐 Safari。Mac 在系统设置 → 辅助功能的朗读相关设置中下载「中文（香港）／粤语」声音，iPhone 在设置 → 辅助功能的朗读相关设置中下载，然后重新打开浏览器。不同系统版本名称不同，浏览器也不一定开放全部已装声音，以页面检测为准。

优先使用本地声音，无需 API 密钥或额外付费服务。声音首次下载需要联网；非本地声音可能联网并由系统服务处理文本。合成语音的多音字、语调可能不准确，不等同于人工校对的真人录音。

## 保存与备份

当前浏览器 localStorage 保存记录，不自动跨设备同步。清除网站数据或隐私模式退出可能丢失进度。文件移动或改名也可能影响本地存储。

「我的足迹」→「导出全部进度」生成 JSON，包含三个模式的本地记录；在另一设备或新版中选择「导入备份」，查看课程和天数后确认替换。仅替换备份含有的课程，其余保留；导入前建议先导出当前记录。导入进行格式校验，不上传服务器。

## 开发运行

Node.js 20+，仓库目录执行：

```sh
npm start
```

电脑本地运行后可打开 `http://localhost:3000`。同一 Wi-Fi 的 iPhone 可访问运行服务的电脑局域网 IP、端口 3000（可能需放行防火墙）。云端运行的 localhost 不可直接从个人设备访问，需平台转发或部署静态网站。

```sh
npm test
node scripts/build-standalone.mjs
```

测试包括完整 90 天课程结构、学习日推进、断档处理、连续天数、备份校验、粤语语音筛选。单文件打包无需第三方依赖。
